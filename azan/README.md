# Azan recordings

Put azan audio files (mp3 or m4a) that you have permission to share in this folder,
then list them in `list.json` so the app offers them to everyone who uses it:

```json
[
  { "file": "my-azan.mp3", "name": "Name shown in the app" }
]
```

This repository is public, so only add recordings you are allowed to publish.
Anyone can also add a recording that stays on their own phone from the Prayer page.
